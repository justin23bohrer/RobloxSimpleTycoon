# SimpleTycoon

A small, server-authoritative Roblox tycoon built with Roblox Studio, Rojo, Git, and OpenCode.

## Local Development

Start the Rojo server from this directory:

```bash
rojo serve
```

Open Roblox Studio, open the Rojo plugin, and connect to the running project. Use Play mode in Studio to test changes.

## Project Files

- `default.project.json`: Rojo mapping.
- `src/`: Lua source files mapped into Roblox services.
- `ARCHITECTURE.md`: system design and ownership rules.
- `TODO.md`: scoped implementation checklist.
- `AGENTS.md`: instructions for coding agents.
