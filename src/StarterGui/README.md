# StarterGui

Syncs into Studio as `StarterGui`. (Rojo ignores this README.)

Empty for now. Cash is shown by the built-in player list (`leaderstats`) and
by the cash panel, which is built by
`StarterPlayerScripts/CashDisplay.client.luau`.

UI here is presentation only. It may read replicated values (like
`leaderstats.Cash`) but must never decide cash, ownership, or purchases.
